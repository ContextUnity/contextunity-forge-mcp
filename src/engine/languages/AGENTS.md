# Language Extractors (`src/engine/languages/`)

Language modules own single-pass Tree-sitter AST traversal and emit canonical `TypedFacts`, `Node`, `Reference`, and `FlowFacts` into `core`. Keep grammar-specific syntax decoding (`ast::visitor::SinglePassExtractor`, scope tracking, receiver hints, and local value-flow) inside the language module, while routing all framework semantics, route/template rules, ORM projections, and ecosystem conventions through declarative `.toml` manifests in [`manifests/`](manifests/). Do not hardcode framework package names, decorator lists, or cross-file resolution policies in language parsers, do not duplicate AST walks across sibling submodules, and do not store untyped `serde_json::Value` maps when a typed field on `TypedFacts` or `FlowFacts` applies.

Preserve extraction throughput by visiting each file in a single cursor pass (`TreeCursor` / `SinglePassExtractor`) with a compact state struct instead of passing more than five mutable arguments or rescanning subtrees. Slice source text directly (`&source[node.byte_range()]`) and defer string allocation until a fact is committed; never compile regexes, parse manifests, lock global mutexes, or allocate temporary `HashMap`/`Vec` collections per AST node when stack arrays or small slices suffice. Calling `.shrink_to_fit()` inside per-node or per-file extraction loops, cloning full `Node` graphs, or serializing JSON on hot extraction paths is strictly forbidden.
