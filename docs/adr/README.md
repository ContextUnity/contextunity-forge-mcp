# Architectural decisions

Accepted decisions live here as owner-approved ADR files with stable IDs,
status, governing constraints, and links to affected contracts. This scaffold
provides their destination; current engineering rules remain in the
[root instructions](../../AGENTS.md) and [architecture](../architecture/README.md).

Create decisions through explicit architectural admission. Agents apply accepted
decisions and refer amendments to the decision owner. A superseding ADR links
the accepted decision it replaces and the affected current architecture.
